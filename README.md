# for_excel / shop

Магазин на React + Vite.

## Структура

- `shop/` — исходники (React 19 + Vite 8)
  - `src/App.jsx` — витрина, корзина, оформление заказа
  - `src/App.css`, `src/index.css` — стили
  - `npm run dev` — локальная разработка (http://localhost:5173)
  - `npm run build` — прод-сборка в `shop/dist/`

## Стек

- React 19
- Vite 8
- localStorage для хранения корзины

## Функционал

- Каталог товаров
- Добавление в корзину / удаление
- Подсчёт итога
- Оформление заказа (имя, телефон, адрес)
- Сохранение корзины между сессиями
